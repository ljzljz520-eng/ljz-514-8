# 高校无障碍路线规划系统

为行动不便的师生（轮椅使用者、拄拐者、视障师生等）提供校园内
**宿舍 ↔ 教学楼 ↔ 食堂 ↔ 图书馆** 的无障碍路线规划：
系统优先避开楼梯与陡坡，返回由**电梯、无障碍坡道、平缓通道**组成的路线，
并给出分步指引、风险提示和与普通步行路线的对比；管理员可在网页端维护校园图数据与算法权重。

## 功能

### 学生端（`/`）
- 下拉选择 / 直接点图两种方式选择起点、终点；
- 「♿ 无障碍优先 / 🚶 普通步行」两种模式；
- SVG 校园地图：坡道（绿色虚线）、陡坡（橙色）、台阶（红色点线）、电梯（蓝色）一目了然；
- 结果面板：路线长度、预计用时、台阶段数、陡坡段数、乘梯次数、综合权重；
- 分步指引（乘梯、坡道坡度、盲道提示、进门提示）；
- 地图上以绿色实线显示无障碍路线、蓝色虚线叠加普通步行路线，直观对比绕行代价；
- 遇超规坡道/窄门等给出警示，全程无障碍时给出确认提示。

### 管理员端（`/admin.html`）
- Token 登录鉴权（默认 `admin / admin123`，存于 `backend/data/auth.json`）；
- **节点维护**：新增/编辑/删除地点，支持类型、楼层、建筑归属、坐标；
- **通道维护**：新增/编辑/删除边，设置类型、坡度、净宽、路面、台阶级数、楼层、盲道、封闭施工等；
- 地图上点选节点或通道即可载入表单；删除节点自动级联删除相连通道；
- 数据校验（悬空端点、非法类型等会被拒绝）；
- **权重热更新**：直接编辑权重 JSON，保存后寻路立即按新权重计算；
- 一键恢复默认校园图。

## 快速开始

无需安装任何第三方依赖（仅使用 Python 3 标准库）：

```bash
cd backend
python3 server.py            # 默认 0.0.0.0:8000
# 或指定端口
python3 server.py --port 8123
```

浏览器打开：

- 学生端：<http://localhost:8000/>
- 管理员端：<http://localhost:8000/admin.html>（`admin` / `admin123`）

可直接执行验证脚本：`python3 tests/smoke_test.py`（需先启动服务）。

## 算法一句话说明

在校园带权无向图上运行 Dijkstra，边权重 =
长度 × 类型乘数 × 路面因子 × **坡度三次惩罚因子** × 净宽因子 × 设施折扣，
台阶与电梯改为按级数/楼层的固定高/低价计价，
从而让"绕一点走坡道+电梯"稳定优于"直走楼梯+陡坡"。
**完整的权重取值、推导和调参方法见 [`docs/algorithm.md`](docs/algorithm.md)。**

## 数据建模约定

- 图为**无向图**（所有边双向可通行；单向管制可用 `blocked` + 拆边扩展）；
- 户外节点 `floor=0`；建筑内楼层用同一 (x, y) 虚拟坐标 + `floor` 偏移展示；
- 楼层之间用 `stairs` 或 `elevator` 类型边连接；
- 边长度可显式给 `length`（米），否则按坐标像素 ×0.55 自动估算。
